# Dr. Aparana Ghosh - Gynecologist Clinic Website

A modern, SEO-optimized website for Dr. Aparana Ghosh's gynecology clinic in Chembur, Mumbai.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📝 To Customize

1. **Update Contact Information**:
   - Phone: Update in `app/components/Navbar.tsx` and `app/components/Footer.tsx`
   - WhatsApp: Update phone number in all WhatsApp links
   - Email: Update in Footer
   - Address: Update clinic address

2. **Add Doctor Photo**:
   - Replace placeholder images with actual doctor photos
   - Upload to Cloudinary or similar service
   - Update image URLs in pages

3. **Add Google Maps**:
   - Get embed code from Google Maps
   - Add to Contact page

4. **Add Content**:
   - Update service descriptions with actual details
   - Add testimonials
   - Add blog posts/health tips
   - Add before/after photos

## 🔧 SEO Setup

- All pages have proper meta titles and descriptions
- Keywords included in metadata
- Structured content with proper headings (H1, H2, H3)
- Image alt tags ready for optimization
