# Baby Treatment GIFs

## How to Add GIF Images

### Step 1: Get GIF Images
- Find or create GIF images related to:
  - Maternal care during pregnancy
  - Newborn care
  - Postpartum care
  - Baby treatments
  - Childbirth care

### Step 2: Save GIF Files
Save the GIF files with these names:
- `baby-treatment-1.gif` - Maternal Care GIF
- `baby-treatment-2.gif` - Newborn Care GIF  
- `baby-treatment-3.gif` - Postpartum Care GIF

### Step 3: Place in Images Folder
Copy the GIF files to:
```
/Users/nidhish.agrawal/draparana/public/images/
```

### Step 4: Verify
The files should be at:
- `/public/images/baby-treatment-1.gif`
- `/public/images/baby-treatment-2.gif`
- `/public/images/baby-treatment-3.gif`

## GIF Requirements

- **Format**: GIF (animated)
- **Size**: 800x600px to 1200x900px (landscape orientation)
- **File Size**: Under 2MB each (optimize if larger)
- **Content**: Should show baby/maternal care treatments
- **Quality**: Clear and professional

## Where GIFs Appear

The GIFs will automatically display on:
- **Homepage** - "Baby & Maternal Care" section
- Shows 3 GIFs in a grid layout
- Responsive design (1 column mobile, 2 tablet, 3 desktop)

## Optimization Tips

- Use online tools like EZGIF.com to optimize GIF size
- Keep animations smooth but file size small
- Ensure good quality and professional appearance
- Test on different devices for performance

## Alternative: Using External URLs

If you prefer to host GIFs externally:

1. Upload GIFs to image hosting (Cloudinary, ImgBB, etc.)
2. Get the URLs
3. Update `app/page.tsx`:
   - Change `/images/baby-treatment-1.gif` to your URL
   - Change `/images/baby-treatment-2.gif` to your URL
   - Change `/images/baby-treatment-3.gif` to your URL
